# UI Craft & Design Token Audit Checklist

> **Stage**: Visual Quality Assurance  
> **Mandatory**: Must be verified for all user-facing interfaces.

---

## 1. Spatial & Visual Rhythm
- [ ] All margins, paddings, and gaps conform to the 4px/8px grid scale.
- [ ] Exactly one primary Call-to-Action button dominates the screen.
- [ ] Secondary and tertiary buttons are visually subordinate (outline/ghost).
- [ ] Elevation shadows are subtle, soft, and consistent across cards.

## 2. Typography & Theming
- [ ] Text hierarchy clearly distinguishes `h1`, `h2`, `h3`, and body text.
- [ ] Numeric data metrics use `tabular-nums` for alignment.
- [ ] Long-form prose is constrained to `max-w-prose` (45–75 characters per line).
- [ ] Dark mode theme tokens function without unreadable low-contrast surfaces.
