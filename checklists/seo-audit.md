# Technical & On-Page SEO Audit Checklist

> **Stage**: Search Engine Optimization  
> **Mandatory**: Must be verified for all public indexable routes.

---

## 1. Technical Crawlability
- [ ] `robots.txt` exists at root and links to `sitemap.xml`.
- [ ] `sitemap.xml` is valid, dynamic, and includes updated `<lastmod>` timestamps.
- [ ] Every indexable page includes an absolute self-referencing canonical URL.
- [ ] Private dashboard and checkout routes are marked `noindex, nofollow`.

## 2. On-Page & Structured Data
- [ ] Title tag length is between 50 and 60 characters with primary keyword.
- [ ] Meta description is between 140 and 160 characters.
- [ ] Exactly one semantic `<h1>` element per page.
- [ ] Complete Open Graph (1200x630px image) and Twitter Card tags configured.
- [ ] Valid Schema.org JSON-LD (Organization, Product, Article, FAQ) verified with Google Rich Results Test.
